

  <h1>🍋 Little Lemon - Restaurant Reservation App</h1>

  <p><strong>Little Lemon</strong> is a responsive, user-friendly web application for booking restaurant tables. It emphasizes reusability, testability, and clean UX/UI design.</p>

  <h2>🚀 Key Features</h2>
  <ul>
    <li><strong>Responsive Design:</strong> A mobile-first approach ensures a seamless experience on all devices.</li>
    <li><strong>Table Reservations:</strong> Book a table via an intuitive booking form.</li>
    <li><strong>Dynamic Time Slots:</strong> Automatically fetches available time slots for selected dates.</li>
    <li><strong>Form Validation:</strong> Formik and Yup handle form state and validation.</li>
    <li><strong>Booking Confirmation:</strong> Users receive confirmation with all booking details.</li>
    <li><strong>Component-Based Architecture:</strong> Built with reusable React components.</li>
    <li><strong>Unit Testing:</strong> Core logic tested using Jest and React Testing Library.</li>
  </ul>

  <h2>🛠️ Technology Stack</h2>
  <ul>
    <li><strong>Frontend:</strong> React, TypeScript</li>
    <li><strong>Styling:</strong> Styled Components</li>
    <li><strong>Routing:</strong> React Router</li>
    <li><strong>Forms:</strong> Formik & Yup</li>
    <li><strong>Testing:</strong> Jest & React Testing Library</li>
    <li><strong>Build Tool:</strong> Vite</li>
  </ul>

  <h2>⚙️ Getting Started</h2>
  <p>Follow the steps below to set up the project locally:</p>

  <h3>📋 Prerequisites</h3>
  <p>Ensure you have <code>Node.js</code> and <code>npm</code> (or <code>yarn</code>) installed.</p>

  <h3>📥 Installation & Setup</h3>
  <pre><code>git clone https://github.com/deepanshu8560/little-lemon-.git
cd little-lemon-
npm install</code></pre>

  <h2>📜 Available Scripts</h2>

  <h3>▶️ Run in Development Mode</h3>
  <pre><code>npm run dev</code></pre>
  <p>Visit <a href="http://localhost:5173" target="_blank">http://localhost:5173</a> in your browser.</p>

  <h3>🧪 Run Tests</h3>
  <pre><code>npm run test</code></pre>
  <p>Launches the test runner in interactive watch mode.</p>

  <h3>📦 Build for Production</h3>
  <pre><code>npm run build</code></pre>
  <p>Optimizes the app for the best performance and outputs to the <code>build</code> folder.</p>
